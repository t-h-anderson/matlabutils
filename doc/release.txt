Version 1.0.4
- gwidgets.Table: add Clipboard controller, Copy selection and Copy visible
  table context-menu actions, and Ctrl+C without replacing user callbacks
- Copy selected cells, rows or columns in displayed order, honoring filters,
  folding and hidden columns; format tab-separated text for spreadsheets

Version 1.0.3
- gwidgets.Table: the all-columns search checkbox immediately reapplies the
  current text and emits FilterChanged when the search mode changes
- Quoted filter values preserve spaces, operator characters and doubled quotes
- Exact displayed column names take precedence over longer prefix matches
- Invalid or ambiguous filters show no rows and an Invalid filter message
- Deferred group-header callbacks can be reconstructed outside their class
  without a private-method access error; row-selection behavior is unchanged

Version 1.0.2
- gwidgets.Table: callback data accepts row and column selections, whose
  indices are vectors, as well as N-by-2 cell selections

Version 1.0.1
- gwidgets.Table: KeyPressCallback receives KeyPressData (Indices,
  DisplayIndices, Key, Character, Modifier), matching the other cell
  callbacks, instead of the KeyPressed event data

Version 1.0.0
- First packaged release, as releases/MatlabUtils 1.0.0.mltbx
- gwidgets.Table: filterable, sortable and groupable table with controller API
  (Column, Group, Sort, Style, Menu, Callback, FilterControl, SelectionControl,
  TooltipControl, MetricControl, Drag), uitable and JavaScript backends, events
  and tooltips
- gwidgets.Table: KeyPressed event and KeyPressCallback for keyboard handling
- gwidgets.Table: Layout can be set to place the table in a grid
- gwidgets: works on MATLAB R2024b (grouped tables, approximate numeric filter
  without the Statistics and Machine Learning Toolbox)
- mlut: utilities and robust table/timetable wrappers; mlut.sl Simulink session,
  data dictionary, bus, model-wrapper and trace utilities; mlut.workspace scoped
  base-workspace access
